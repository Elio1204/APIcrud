# API CRUD de Producción

API REST básica para gestionar datos de producción (CRUD).  
Desarrollada con **Node.js** y conexión a base de datos.  
Proyecto orientado a practicar backend y manejo de datos.

## 🚀 Funcionalidades
- Crear, leer, actualizar y eliminar registros.
- Endpoints REST con manejo de JSON.
- Conexión a base de datos (MySQL).

## 🛠 Tecnologías
- Node.js
- Express
- MySQL
- JavaScript

## 📦 Instalación
```bash
git clone https://github.com/Elio1204/api_produccion.git
cd api_produccion
npm install
npm start
